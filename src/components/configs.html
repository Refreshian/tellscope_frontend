PostgreSQL

Установка

sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo apt-key add -
sudo apt-get update
sudo apt-get -y install postgresql

Пользователь и БД

sudo su - postgres
psql -c "alter user postgres with password '****'"   # редактируйте пароль
createuser dbuser
createdb datadb -O dbuser
psql datadb
  • Список БД: \l (в psql)
  • Удалённый доступ: listen_addresses='*' и pg_hba.conf правило host datadb dbuser 0.0.0.0/0 md5

Elasticsearch 8.x

Установка

echo "deb [trusted=yes] https://mirror.yandex.ru/mirrors/elastic/8/ stable main" | sudo tee /etc/apt/sources.list.d/elastic-8.x.list
sudo apt update
sudo apt install -y elasticsearch

Сервис

sudo systemctl enable elasticsearch
sudo systemctl start elasticsearch
sudo systemctl status elasticsearch
При необходимости — вручную создать /etc/systemd/system/elasticsearch.service и настроить права для пользователя elasticsearch.

Redis

Celery

Базовый запуск

# worker
celery -A run_celery worker --loglevel=info

# beat
celery -A run_celery beat --loglevel=info

Отладка / перезапуск

sudo pkill -f celery          # остановить
find . -type d -name "__pycache__" -exec rm -r {} +
celery -A main.celery_app worker --loglevel=info --concurrency=1 --pool=solo
Проверка задач: celery -A celery_app inspect registered

Qdrant

Volume + Сервис

docker volume create qdrant_data
Сервис: /etc/systemd/system/qdrant.service (docker run с портами 6333/6334, volume qdrant_data).

Запуск / Статус

sudo systemctl daemon-reload
sudo systemctl start qdrant
sudo systemctl status qdrant
sudo systemctl enable qdrant
Проверка: curl http://localhost:6333 или dashboard: http://host:6333/dashboard

Продвинутая конфигурация (yaml)

/opt/qdrant/config/production.yaml
# монтируется в контейнер через systemd unit

Nginx & Supervisor (FastAPI)

Supervisor конфиг

Файл: /etc/supervisor/conf.d/tellscope.conf

[program:fastapi_app]
command=/home/dev/tellscope_app/tellscope_backend/venv_py312_clean/bin/uvicorn main:app --host 0.0.0.0 --port 5000 --workers 1
directory=/home/dev/tellscope_app/tellscope_backend
environment=PYTHONPATH="/home/dev/tellscope_app/tellscope_backend",CUDA_VISIBLE_DEVICES="3"
autostart=true
autorestart=true
stderr_logfile=/var/log/fastapi_app.err.log
user=dev

sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl restart fastapi_app
sudo supervisorctl status fastapi_app

Nginx

sudo nano /etc/nginx/nginx.conf
sudo nginx -t && sudo systemctl reload nginx
Конфиги: /etc/nginx/conf.d/tellscope40.headsmade.com.conf
